# about
A super duper cool handheld game console in a style of an Nintendo DS. Instead of two normal displays I replaced them with two e-ink displays and the chip with an ESP32-C6. Designed and built by me, from the electronics and PCB to the enclosure and firmware.

# features
It features two e-inks, eight buttons, 1 000 mAh LI-PO battery, a step up convertor + battery charger in one and mainly an ESP32-C6, which you can take out and use for other projects. Games are dyno, snake and more to come or you could make.

# why did I create it
I always wanted a Nintendo DS it felt like the coolest thing to me. Now I have the knowledge and practice on electronics to make my own. I also wanted to use e-ink, because they're just so cool and it feels more like the real Nintendo DS with the black and white and the quite slow refresh rate.
